# logistik-shipping-fe

Aplikasi Next.js untuk Cargo Deck (halaman dan API dalam satu proyek). Cara setup, struktur folder, dan skrip database ada di [README utama](../README.md).

Perintah yang biasa dipakai, dari folder ini:

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm lint
pnpm build
```
